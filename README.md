# UrbanSketch 样条空间选取库

内存型样条场景库：由上层画布调用，提供**批量装入样条场景**与**按区域选取**两个能力。
数据仅存进程内存，无任何外部服务依赖。

## 能力

- `loadSplines(splines)`：批量装入样条（替换场景原有内容）。每条样条有唯一 ID，
  由首尾相接的三次贝塞尔段组成；允许自交、闭合、退化为线段或点。只计算中心线。
- `select(region, mode)`：按选区选取。
  - 选区 = 一个简单多边形外环 + 零个或多个孔洞；外环与孔洞边界都属于选区。
  - `mode: 'intersect'`：样条上至少一个点属于选区即命中。
  - `mode: 'contain'`：样条上所有点都属于选区才命中（中途穿出区外/孔洞即不命中）。
  - 每条命中样条返回中心线落在选区内的全部**最大闭参数区间**（第 i 段对应全局参数
    [i, i+1]），按参数递增排列，可连接的区间已合并；单点接触保留为
    `start === end` 的区间；整段退化为区内一点时覆盖该段完整参数范围。

## 使用

```ts
import { createSplineScene } from 'urbansketch-spline-select';

const scene = createSplineScene();
scene.loadSplines([
  {
    id: 'road-1',
    segments: [
      { p0: { x: 0, y: 0 }, p1: { x: 1, y: 2 }, p2: { x: 3, y: 2 }, p3: { x: 4, y: 0 } },
    ],
  },
]);

const hits = scene.select(
  {
    outer: [{ x: -1, y: -1 }, { x: 5, y: -1 }, { x: 5, y: 5 }, { x: -1, y: 5 }],
    holes: [],
  },
  'intersect',
);
// hits: [{ id: 'road-1', intervals: [{ start: 0, end: 1 }] }]
```


## 实现要点

- 对每条贝塞尔段，求其与选区全部边界的交点参数（曲线代入边的直线方程得三次多项式，
  用导数划分单调区间 + 二分求根，相切零点通过极值识别）；与边共线的段改用投影参数
  界定重叠范围。
- 交点参数把 [0,1] 切成子区间，中点做“点在选区”分类（射线法 + 边界容差判定），
  候选参数点本身单独判定，最后按参数相接关系合并（不引入合并容差，
  1e-7 的短间隙不会被吞掉）。
- 几何容差：`max(1e-9, 坐标规模 × 1e-12)` 英尺；区间端点参数误差 ≤ 1e-9。

## 性能

验收规模：2000 条样条 × 8 段、选区含孔洞共 64 条边（一半样条强迫穿过选区触发完整裁剪，
另一半散布在 ±100000 英尺范围）。在本机（Apple Silicon, Node 24）实测：

- `intersect` 单次选取约 **41ms**（810 条命中）
- `contain` 单次选取约 **27ms**（23 条命中）

远低于 5 秒上限（耗时不含场景装入）。性能用例见 `test/perf.test.ts`，
运行 `npm test` 时会打印实测耗时。
