# diversity-sampling

主动学习的多样性选样库（TypeScript）。由上层实验流程直接调用：特征、簇摘要（代表点）
和标注状态保存在进程内；本库不负责训练模型或执行聚类。

## 使用

```js
import { DiversitySession } from "diversity-sampling";

const session = new DiversitySession({
  samples: [{ id: 0, features: [/* 16 个 0-255 整数 */] }, ...],
  representatives: [{ features: [...], weight: 100 }, ...], // weight 为 1-10000 整数
  labeledIds: [/* 可选，已标注样本 id */],
});

const batch = session.recommend(200); // 1-200，返回有序 id 列表，不改变标注状态
session.markLabeled(batch.slice(0, 50)); // 只有显式标注的样本才从后续候选中排除
const next = session.recommend(200);
```

## 选样规则

- 距离：各维差值平方之和（16 维，最大 16·255² = 1040400）。
- 代表点覆盖代价：到所有已标注样本及本批已选中样本的最小距离；两类均为空时取 1040400。
- 总覆盖代价：各代表点覆盖代价 × 权重之和。
- 每批按顺序逐条贪心：每步选取使总覆盖代价下降最多的候选，并列取 id 较小者；
  即使下降量为零也继续按规则选满；未标注样本不足时返回全部剩余样本。
- 推荐不改变标注状态；标注状态不变时重复请求结果一致；较短请求是较长请求的前缀。

## 实现

贪心采用懒惰贪心（CELF）：覆盖收益关于已选集合单调不增（次模性），堆中保存的收益
是精确上界，因此懒惰求值与每步全量重算得到完全相同的序列。所有距离、加权收益与
并列判定均为整数精确计算（float64 可精确表示范围内）。

复杂度（n 样本、m 代表点、k 批量）：首轮收益计算 O(n·m·16)，之后每步只重算少数
候选；标注一条样本 O(m·16)。额外工作内存 O(n + m)，20000 样本 / 2000 代表点 /
批量 200 时实测首批约 1.1 s、额外内存约 2 MiB（限制：60 s / 64 MiB）。

## 构建与测试

```sh
npm install
npm test   # 先 tsc 构建，再运行 node:test 测试
```

测试包含：小规模数据与直接按业务定义计算的暴力参考实现逐步对照（已有标注、高权重
代表点、相同特征、零收益并列）、推荐后部分标注与新会话一致性、前缀性质，以及完整
规模（20000 / 2000 / 200）的耗时与峰值额外内存报告。
