# diversity-sampling

主动学习的多样性选样库（TypeScript 实现），由上层实验流程直接调用。
特征、簇摘要和标注状态保存在进程内；本库不负责训练模型或执行聚类。

## 运行要求

- Node.js >= 22.18（利用原生 TypeScript 类型擦除直接运行 `.ts`，零第三方依赖）。
- `npm install` 之后 `npm test` 即可运行全部自动化测试。

## API

```ts
import { createSession } from "diversity-sampling";

const session = createSession({
  samples: [{ id: 0, features: [/* 16 个 0-255 整数 */] }, ...],
  representatives: [{ features: [...], weight: 100 }, ...], // weight 为 1-10000 整数
  labeledIds: [/* 已标注样本 ID */],
});

const batch: number[] = session.recommend(200); // 1-200 条，按产生顺序排列
session.markLabeled([batch[0]!, batch[1]!]);    // 只有显式标记的样本才从候选中排除
const next = session.recommend(200);
```

- `createSession(config)`：建立选样会话。样本 ID 为唯一非负整数；样本与代表点均为
  16 维、每维 0-255 整数。代表点不是待选样本，不要求出现在样本池中。
- `recommend(count)`：请求下一批推荐（1 到 200）。推荐不改变标注状态、不预占样本；
  未标注样本不足时返回全部剩余样本。
- `markLabeled(ids)`：把指定样本记为已标注（幂等）。标注值本身不参与计算。

## 选样规则

- 距离：各维差值平方之和（16 维 0-255 特征，最大 1040400）。
- 代表点覆盖代价：到所有已标注样本及本批已选样本的最小距离；两类均为空时取 1040400。
- 总覆盖代价：各代表点覆盖代价乘以自身权重后求和。
- 一批推荐按顺序逐条产生：每步选取使当前总覆盖代价下降最多的候选，下降量相同
  选 ID 较小者；选中后按新的覆盖情况决定下一条。每批不重复选择同一 ID；下降量
  均为零时仍按规则选满。

## 实现要点

- **惰性贪心（CELF）**：收益随已选集合增大单调不增，堆中保存收益上界；堆顶过期
  则按当前状态重算，新鲜堆顶即精确的贪心选择（含 ID 并列判定），结果与逐步暴力
  重算完全一致，但避免每轮全量重算。
- **特征去重**：特征完全相同的候选收益始终相等，合并为一组、组内按 ID 升序选出，
  避免大量相同收益导致的重复重算（退化场景下仍保持毫秒级）。
- **精确性**：距离、权重乘积均为整数且单项小于 2^53；加权收益用 number 累加并
  定期并入 BigInt，全程无舍入误差，并列判定精确。
- **内存**：特征以 `Uint8Array` 紧凑存储，按需计算距离，不保存距离矩阵。
  20000 样本 + 2000 代表点规模下实测额外内存约 10 MiB（限制 64 MiB）。

## 测试

```sh
npm install
npm test
```

- `test/correctness.test.ts`：小规模数据逐步对照直接按业务定义计算的暴力参考实现，
  覆盖已有标注、高权重代表点、相同特征、零收益并列；验证“推荐后只标注一部分，
  再次推荐与仅包含实际已标注集合的新会话完全一致”、确定性、前缀性质与输入校验。
- `test/degenerate.test.ts`：大规模相同特征与全体零收益两种退化场景下的正确性与耗时。
- `test/scale.test.ts`：完整规模（20000 样本、2000 代表点、每批 200）测试，
  报告首批耗时与峰值额外内存，并核对返回数量、唯一性及已标注样本排除情况。
  本机实测：首批约 1.3 秒（限制 60 秒），额外内存约 10 MiB（限制 64 MiB）。
